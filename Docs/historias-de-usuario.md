# Historias de usuario

**Guardar datos:**

- La solución necesita una forma en la que cargando archivos excel o csv podamos cargar datos historicos previos sobre registros de compra que se han realizado antes.
- El sistema debe proveer una forma en la que cuando registremos nuevas compras podamos publicarlo al sistema de sugerencias para que actualice sus datos con datos recientes.

**Chat con IA:**

- Debido a que el sistema tendra datos historicos y recientes de las compras de los usuarios necesitamos que con IA pueda sugerir una venta o ventas para preparar cargamento segun las preferencias que han tenido los clientes.
- Tambien es necesario tener un chat con IA para poder realizar consultas de los datos que se tienen guardados y de esa forma el LLM puede buscar en la base de datos y hacer reportes a los usuarios en un chat.

**Dashboard**

- Los datos guardados en el sistema deben poder visualizarse en un dashboard para proveer información útil para la toma de decisiones gerenciales.
